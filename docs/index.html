Attractor Patterns for Blender

Twenty-one pattern modifiers that put perforations, textures and cutouts on any object. Every pattern is driven by point and line attractors: move an empty or bend a curve and the pattern grows, shrinks, rotates or opens up around it.

Step 0

Install

  1. Download attractor_patterns-0.2.0.zip. Don't unzip it.

  2. In Blender, open Edit › Preferences › Get Extensions. Click the ⌄ menu at the top right and choose Install from Disk…, then pick the zip.

    You can also drag the zip straight into the Blender window.

  3. Close Preferences. In the 3D Viewport press N to open the sidebar and click the Patterns tab.

Blender 4.5 or newer is recommended. It has the Manifold boolean solver, which cuts a pattern in about a second. Blender 4.2 falls back to the Exact solver, which gives the same result but can take minutes on dense patterns.
Tutorial

Your first perforated panel

This walks through a flat panel. The same steps work on curved objects; see curved surfaces below.

  1. Make a panel with a good UV map

    Add a Plane (Shift A › Mesh › Plane) and scale it to the panel size, for example 640 × 360 mm. Apply the scale with Ctrl A › Scale.

    The pattern is laid out on the UV map at real size, so the UVs must keep the object's proportions. A default plane is fine once its scale is applied. For other objects use UV › Smart UV Project or Project from View, and avoid stretching UVs to fill the square.

  2. Add an attractor

    Place the 3D cursor where you want the effect and click Point or Line in the Patterns tab.

    A point attractor is an empty in the AP Attractor Points collection. A line attractor is a curve in AP Attractor Lines; edit it like any curve, or drop any mesh into that collection to use its edges. Add as many as you like.

  3. Add a pattern

    Select the panel and click a pattern name, for example Round Perforation. It's added as a Geometry Nodes modifier in Preview mode, sized so about 25 cells fit across the object.

    Preview colours each opening by the field, so you can see where the attractors reach. Move an attractor and the pattern follows live.

  4. Tune it in the modifier panel

    Open the Modifier properties (the wrench). The inputs are grouped into four panels:

    Pattern sets the cell size and seed. Attractors sets the radius, falloff curve and how several attractors combine. Fabrication sets the minimum bridge, minimum hole, edge margin and corner radius your cutter can handle. Output sets the mode and sheet thickness.

  5. Choose an output mode and export

    Switch Output › Mode to the geometry you need, then apply the modifier (Ctrl A over it) or export directly.

    Cut Through

    Real holes through a sheet of the given thickness. For laser, waterjet and 3D printing.

    Engrave

    Shapes sunk into the surface by Depth. For CNC pockets and textures.

    Emboss

    Shapes raised above the surface by Depth. For relief, moulds and studs.

    Preview

    Fast, flat shapes coloured by the field. For designing and rendering.

    Open surfaces such as a plane are thickened inward by Thickness, so the result is always a closed solid that 3D prints and booleans cleanly.

What each pattern does with the field

Each pattern maps the attractor field onto one thing about its shapes. These are the same 21 families as the 2D playground, with the same parameters.

Beyond flat panels

Curved surfaces

The pattern is drawn flat on the UV map at real scale, then every vertex is projected back onto the surface. A 24 mm cell stays 24 mm on a cylinder or a sphere, shapes bend with the surface, and the edge margin follows the mesh's own open edges and holes.

The attractor field is measured in 3D, so an empty floating beside a lamp shade or a curve wrapped around a column works the way you'd expect.

Unwrap cylinders with UV › Cylinder Projection or a seam and Unwrap. For spheres, a seam-and-unwrap or Smart UV Project keeps cells more even than the default UV sphere map.

Good to know

Tips and limits

  • Apply scale first. Distances are measured in the object's local space, so an object scaled ×2 doubles every length.
  • UVs set the layout. The pattern stretches wherever the UVs do. Shapes that cross a UV seam are dropped, so place seams where the pattern can stop.
  • Design in Preview. Cutting is the slow part. Stay in Preview while you place attractors, then switch modes.
  • Reaction Diffusion is heavy. It reruns the whole simulation on every change. Lower Iterations or Resolution while designing.
  • Flow lines on closed surfaces. A line that wraps all the way round a cylinder can fail with the Manifold solver; the modifier then falls back to Exact, which is slow there. Engrave always works.
  • Patterns keep working without the add-on. The node groups are saved in your .blend, so files open fine on machines without it. Use Rebuild Node Groups in the Patterns tab after updating the add-on.

Using the asset library instead

If you'd rather not install an add-on, download attractor_patterns.blend, add its folder under Preferences › File Paths › Asset Libraries, and drag patterns from the Asset Browser onto a mesh. Put your attractors in collections and pick them in the modifier's Attractor Points and Attractor Lines fields.
